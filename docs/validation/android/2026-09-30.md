## 模拟器集成测试

1. DNS64 UDP 查询经过真正的 Android TUN 和用户态网络栈。
2. DNS64 TCP 查询经过同一路径。
3. Android `InetAddress.getAllByName()` 获得本工具前缀的合成 AAAA。
4. 合成 IPv6 → NAT64 → 主机 IPv4 TCP 回显服务，32 KiB 数据一致。
5. 合成 IPv6 → NAT64 → 主机 IPv4 UDP 回显服务，报文一致。
6. 直接 IPv4 不能访问上述同一主机 TCP 服务。
7. 连续三次停止、重启后仍能完成 DNS64 查询。

测试发现并修复了 Android TCP socket 延迟创建文件描述符导致 `VpnService.protect()` 失败的问题。
目前在 protect 前显式绑定本地临时端口，再绑定底层物理网络。
